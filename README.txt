변경사항
- 대학 찾기 데이터를 큰 대학군 3개가 아니라 53개 대학 개별 참고 범위로 교체
- 5등급제 참고 범위를 그대로 반영
- 고1, 고2만 선택 가능
- 학과 찾기 25문항 유지
- 대학 결과를 상향 / 적정 / 안정 / 더 노력한다면 으로 분류
- 각 대학 옆에 참고 등급 범위 표시
- 상향 및 목표 대학에는 필요한 등급 향상 폭 표시

중요
이 대학별 숫자는 사용자 제공 참고값입니다.
대학·학과·전형별 실제 합격 결과나 공식 입시결과를 의미하지 않습니다.

충북고 학술제를 위한 사이트입니다.
